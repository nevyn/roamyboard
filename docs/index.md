# Docs

- [Glossary](glossary.md): canonical terms for modules, the case, the joint and the firmware, with a labelled diagram.
- [Firmware](firmware.md): the ZMK module and config in `zmk/`: how the chain is read, key module count and anchors, the builds, the socket board pins, building and flashing.
- [Landing page](index.html): what the Roamyboard is, a 3D view of a half, photos of the build so far, and links to the three pages below. `.github/workflows/pages.yml` publishes `docs/` as the site root whenever a page changes on main: https://nevyn.github.io/roamyboard/ is this page, and each page below is at its folder name (`/assembly/`, `/order/`, `/layout/`). The pages' relative paths never leave `docs/`, so the same files work served from the repo root: `git lfs pull` (the 3D models are in Git LFS), run `python3 -m http.server` in the repo root and open `/docs/`. The pages fetch the keymaps from `docs/keymaps`, a symlink to `zmk/config`, so there is no copy of them; the workflow publishes copies at `/keymaps/`. The old `/docs/<page>/` URLs redirect to the new ones, keeping the query and the anchor.
- [Assembly guide](assembly/index.html): printing, soldering, assembling, flashing and testing a half, with 3D views from the Cadova model. Published at https://nevyn.github.io/roamyboard/assembly/.
- [Order page](order/index.html): the configurator a buyer picks a build on — halves, columns, rows, curve, case colour, switches and keycaps — with a line-by-line price in euros and kronor and a `mailto:` that carries the configuration as a link. `docs/parts.js` holds the parts and their vendor prices, shared with the assembly guide's parts list; `docs/order/catalog.js` holds the filament, switch and keycap catalogues; `docs/order/geometry.js` ports the case model's arc so the curve shown is the curve the case prints at; `docs/order/keys.js` maps a module position to its keymap column, the same mapping the layout page draws, so the page can letter the keys and paint by key group. Published at https://nevyn.github.io/roamyboard/order/. `node --test docs/order/order.test.js` checks the geometry against `case/Case design.md` and that no part reaches the bill unpriced.
- [Keyboard layout](layout/index.html): the default layout, layer by layer, drawn as two halves of modules with a key module count per half. The page fetches and parses `zmk/config/roamyboard_split.keymap` (through `docs/keymaps`) when it loads, so it has no copy of the layout. Published at https://nevyn.github.io/roamyboard/layout/. `node --test docs/layout/keymap.test.js` checks the parser and that every binding in both keymaps has a label.
